Welcome to `histlog`.

== What This Project Is

histlog is an Elixir implementation of a log-structured shell history system.
It captures interactive shell activity as append-only per-session NDJSON streams, then consolidates closed sessions into daily materialized files.

== First Steps

* Read xref:architecture:13-histlog-v1-specification.adoc[the v1 specification] for the architectural contract.
* Use xref:manual:index.adoc[the manual] for CLI commands and local workflows.
* Run `make test` and `make lint` before committing implementation changes.
