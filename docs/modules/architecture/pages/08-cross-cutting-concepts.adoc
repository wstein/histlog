= Cross-Cutting Concepts
:page-layout: default

The same integrity rules apply across writers, importers, consolidators, and queries.

== Shared Concerns

* NDJSON is the subsystem boundary.
* `hook-state/` JSON is non-canonical adapter state used only to bridge short-lived hook processes.
* Events are immutable truth; daily files are derived views.
* Sequence numbers are session-local and gapless.
* Redaction happens before persistence.
* Corrupt sessions are quarantined at file granularity.
* Atomic writes use temporary files followed by rename.
