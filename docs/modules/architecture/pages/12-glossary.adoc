== Terms

NDJSON::
Newline-delimited JSON. histlog writes one JSON object per line.

Session file::
One append-only NDJSON file written by a single shell session.

Closed session::
A session file that was moved from `sessions/live/` to `sessions/closed/`.

Consolidation::
The process that validates closed sessions and materializes rows into `histlog.db`.

Processed-session checkpoint::
A SQLite row that records which closed session file has been materialized, with record counts and source checksum.

histlog.db::
The local SQLite database that stores derived query rows. It is rebuilt from canonical closed session files when needed.

history_view::
The preferred SQLite read surface for command history. It joins normalized projection tables into user-facing query rows.

sessions_view::
The preferred SQLite read surface for session summaries.

Quarantine::
The storage area for malformed session files that should not block other sessions.
