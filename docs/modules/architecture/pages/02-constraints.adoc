= Constraints
:page-layout: default

histlog v1 intentionally favors explicit log-structured files over hidden storage services.

== Technical Constraints

* The implementation language is Elixir.
* Canonical event streams use NDJSON.
* Each CLI session writes one append-only logfile.
* histlog does not use SQL as canonical storage, a daemon, a long-running OTP service, or a long-running indexing engine.
* SQLite is used only as a local derived query materialization.
* All runtime workflows are short-lived CLI invocations; recurring work is started by the user or an external scheduler.
* Subsystems exchange data through files rather than shared mutable state.

== Operational Constraints

* Consolidation must be idempotent and atomic.
* Corrupt sessions must be quarantined without blocking valid sessions.
* Shell-derived strings are untrusted and must pass through redaction before persistence.
