= Introduction And Goals
:page-layout: default

histlog exists to make interactive shell history useful as durable operational evidence without requiring a database in v1.

== Product Goals

* Capture shell sessions, commands, working directories, durations, and exit statuses.
* Preserve raw command evidence as immutable NDJSON events.
* Keep interactive shell overhead low by deferring analysis to consolidation.
* Support future database or index targets as derived materializations.

== Stakeholders

* Shell users who want reliable command history.
* Maintainers who need deterministic file formats and tests.
* Operators who need inspectable recovery from partial or corrupt sessions.
* Future integrations that consume event streams, derived execution rows, or manifests.
