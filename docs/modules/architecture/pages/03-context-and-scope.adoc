= Context And Scope
:page-layout: default

histlog sits between interactive shells and file-based history analysis.

== System Context

Shell integrations write event records through `Histlog.SessionWriter`.
Closed session files are consumed by `Histlog.Consolidator`, which produces daily canonical streams, derived execution rows, and manifests.

== External Interfaces

* Shell history sources: zsh, bash, fish, and legacy/native NDJSON import files.
* Filesystem storage under `~/.local/share/histlog/` by default.
* CLI commands for consolidation, import, tailing, and simple queries.
