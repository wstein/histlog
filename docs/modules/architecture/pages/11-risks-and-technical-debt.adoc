= Risks And Technical Debt
:page-layout: default

The current implementation is an MVP foundation with explicit remaining risks.

== Open Risks

* Generated zsh, bash, and fish hook scripts are implemented, but they still need manual testing in real interactive shells.
* Bash hook integration uses the `DEBUG` trap and does not compose with a pre-existing `DEBUG` trap in v1. Users with existing bash instrumentation may need to choose zsh/fish or manage trap ordering manually.
* Import parsers cover representative fixtures but not every shell-history edge case.
* Redaction uses conservative pattern matching and should continue to grow from real-world samples.
* SQLite schema evolution and rebuild behavior need continued hardening as the projection grows.
* `exqlite` adds a native dependency path; clean installs should be tested across supported operating systems.
