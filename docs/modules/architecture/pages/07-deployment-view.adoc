= Deployment View
:page-layout: default

histlog v1 is packaged as a Mix application with an escript command-line entrypoint.

== Local Runtime

The default data root is `~/.local/share/histlog/`.
Development and verification run through the repository `Makefile` and Mix.

== Generated Artifacts

The generated escript binary is ignored by Git.
Build it locally with:

[source,sh]
----
cd app
mix escript.build
----

From the repository root, `make build` compiles and rebuilds `app/histlog`.
`make install` creates `${PREFIX:-$HOME/.local}/bin/histlog` as a symbolic link to that repo-built escript.
This is the preferred local-development install scheme because shell hooks invoke a short-lived executable and pick up rebuilds immediately.
