= Install And Build
:page-layout: default

The Elixir app exposes an escript entrypoint.

histlog uses `exqlite` for the local `histlog.db` query materialization.
Most development installs use precompiled SQLite artifacts through `exqlite`, but some platforms may need normal native build tools available for Mix dependencies.
histlog requires Elixir 1.18 or newer because it uses the built-in `JSON` module.

[source,sh]
----
cd app
mix escript.build
./histlog query --help
----

From the repository root, `make build` compiles the application, builds `app/histlog.escript`, and writes `app/histlog`.
Because `histlog.db` uses the native `exqlite` NIF, `app/histlog` is the supported local launcher for database-backed commands.
The escript is built as a CI artifact, but the launcher plus compiled BEAM/NIF files are required for SQLite-backed workflows.

[source,sh]
----
make build
make install
----

`make install` symlinks `${PREFIX:-$HOME/.local}/bin/histlog` to the repo-built `app/histlog` launcher.
That local-development install keeps interactive shells on the latest rebuilt escript without a daemon.
