= Paths And Sessions
:page-layout: default

`paths` summarizes filesystem locations observed as working directories and path-like command arguments.
For closed sessions and imports, argument paths come from materialized `command_paths` facts in `histlog.db`.
For live sessions, histlog derives the same shape from active session NDJSON until the session is consolidated.
Paths under the current user's home directory are displayed and materialized with a `~` prefix rather than an absolute home path.

[source,sh]
----
histlog paths --root /tmp/histlog --date 2026-05-06
histlog paths --today
histlog paths --plain
histlog paths --json
----

`sessions` lists recorded shell sessions and can include additional metadata.

[source,sh]
----
histlog sessions --root /tmp/histlog --date 2026-05-06
histlog sessions --today
histlog sessions --details
histlog sessions --json
----

Both commands accept the query-family time shortcuts: `--today`, `--yesterday`, `--week`, `--since`, `--before`, and `--time`.
