= Log Format
:page-layout: default

histlog stores canonical history internally as compact NDJSON.
This page documents the on-disk truth for debugging, verification, and tooling work.
The public query command does not expose NDJSON; use `histlog export --format ndjson` for line-oriented export.

== Session File Example

[source,json]
----
{"event":"session_started","host":"Mac","process_id":80615,"parent_process_id":0,"schema_version":1,"seq":1,"session_id":"XBQxaBoA6-rWLbEKJqoAIw","shell":"fish","timestamp":"2026-05-06T21:42:54.828788Z"}
{"command":"mix test","command_id":1,"event":"command_defined","schema_version":1,"seq":2,"timestamp":"2026-05-06T21:43:07.251237Z"}
{"event":"folder_defined","folder":"/repo","folder_id":1,"schema_version":1,"seq":3,"timestamp":"2026-05-06T21:43:07.252000Z"}
{"command_id":1,"completeness":"complete","cwd_id":1,"duration_ms":331,"event":"execution_observed","exec_id":1,"exit_status":0,"schema_version":1,"seq":4,"timestamp":"2026-05-06T21:43:06.769Z"}
{"event":"session_ended","schema_version":1,"seq":5,"timestamp":"2026-05-06T21:45:00Z"}
----

Session files store the `session_id` only in `session_started`.
Later records rely on the file boundary and sequence number.

== Derived Execution Row

[source,json]
----
{"event":"execution","session_id":"XBQxaBoA6-rWLbEKJqoAIw","exec_id":1,"command":"mix test","cwd":"/repo","timestamp":"2026-05-06T21:43:06.769Z","duration_ms":331,"exit_status":0,"completeness":"complete","shell":"fish","host":"Mac"}
----

Derived execution rows are materialized views, not canonical truth.

== Partial Execution

[source,json]
----
{"command_id":1,"completeness":"partial","cwd_id":1,"duration_ms":null,"event":"execution_observed","exec_id":2,"exit_status":null,"schema_version":1,"seq":6,"timestamp":"2026-05-06T21:44:00Z"}
----

Partial executions are valid because shell hooks can miss completion data.

== Database Checkpoint

[source,sql]
----
SELECT session_file, session_id, date, events_count, executions_count
FROM processed_sessions
WHERE date = '2026-05-06';
----

`histlog.db` stores materialized execution rows plus processed-session checkpoints.
Closed session NDJSON remains the canonical source; the database is rebuilt from those files when needed.

== Redacted Command

[source,json]
----
{"command":"deploy token=[REDACTED]","command_id":1,"event":"command_defined","redacted":true,"schema_version":1,"seq":2,"timestamp":"2026-05-06T21:43:07Z"}
----

Redaction happens before persistence.
