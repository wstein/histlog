= Sync, Rebuild, Info, And Doctor
:page-layout: default

`sync` reads closed sessions, writes query rows to `$HISTLOG_ROOT/histlog.db`, and prints a human-readable report by default.
Without `--date`, it materializes all closed session dates so query-family commands can see the full closed history.

[source,sh]
----
histlog sync --root /tmp/histlog
histlog sync --root /tmp/histlog --date 2026-05-06
histlog sync --root /tmp/histlog --date 2026-05-06 --json
histlog rebuild --root /tmp/histlog --date 2026-05-06
----

`sync --date YYYY-MM-DD` limits materialization to one day.
When `$HISTLOG_ROOT` does not exist yet, `sync` creates the root and initializes `histlog.db`.
If the local database projection schema is incompatible, `sync` may drop and recreate the derived projection from canonical NDJSON. The report includes `schema_reset: true` when that happens; use `--json` for the full machine-readable report.
Use `histlog rebuild` when the intent is maintenance or repair: it deletes database rows and checkpoints for the selected date scope, then rematerializes them from current closed sessions.

Materialization commits inside a SQLite transaction:

* validate closed session NDJSON
* quarantine malformed session files
* insert normalized sessions, command text, paths, command rows, command argument path facts, and processed-session checkpoints
* commit all database changes together

If a run stops partway through, SQLite rolls back the incomplete transaction.
The next run can retry safely without duplicating already processed sessions.

`info` shows runtime information such as version, paths, and environment variables.
`doctor` diagnoses that state, including schema checks, materialization counts, SQLite integrity, and orphan relationship checks. It prints recommendations when checks fail.
`doctor` opens the database read-only and does not create a missing data root.

[source,sh]
----
histlog info zsh --root /tmp/histlog
histlog doctor zsh --root /tmp/histlog --date 2026-05-06
histlog doctor zsh --root /tmp/histlog --date 2026-05-06 --json
----

Use `--json` when scripts need the full database verification details.
