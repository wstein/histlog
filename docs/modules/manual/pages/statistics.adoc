= Statistics
:page-layout: default

`statistics` shows a compact overview of materialized history and currently live sessions.

[source,sh]
----
histlog statistics
histlog statistics --date 2026-05-06
histlog statistics --today
histlog statistics --top 20
histlog statistics --json
histlog statistics --plain
----

The report includes:

* total and unique command counts
* session, imported, and live command counts
* successful and failed command counts
* first and last observed timestamps
* top commands
* top paths

`statistics` is a query-family command. It reads the same shared source stream as `query`, `commands`, `paths`, `sessions`, and `export`: the SQLite projection plus currently live session files.
It accepts the same time shortcuts as the other query-family commands: `--today`, `--yesterday`, `--week`, `--since`, `--before`, and `--time`.
