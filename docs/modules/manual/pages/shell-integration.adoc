= Shell Integration
:page-layout: default

histlog does not edit shell rc files.
Print the integration code and opt in explicitly:

[source,sh]
----
eval "$(histlog init zsh)"
eval "$(histlog init bash)"
histlog init fish | source
----

Pass the shell explicitly when writing setup files.
`histlog init` auto-detects the shell from `HISTLOG_SHELL`, then `SHELL`, and then reports an error when detection fails.

Pin an exact executable with an absolute path:

[source,sh]
----
eval "$(histlog init zsh --binary /absolute/path/to/histlog)"
----

When `--binary` is supplied, the generated script assigns `HISTLOG_BIN` directly instead of honoring a pre-existing environment value.

Durability modes are `safe`, `balanced`, and `fast`; `balanced` is the default.

[source,sh]
----
eval "$(histlog init zsh --durability balanced)"
----

The generated shell code is a thin capture adapter.
It calls the internal hook boundary and does not construct history records itself.

Bash integration uses the shell `DEBUG` trap.
In v1 it installs histlog's trap directly and does not compose with an existing `DEBUG` trap; users with complex bash instrumentation should prefer zsh or fish integration, or review their trap setup before enabling histlog.
