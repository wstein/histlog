= Consolidate And Verify
:page-layout: default

`consolidate` reads closed sessions for the selected day, writes query rows to `$HISTLOG_ROOT/histlog.db`, and emits a JSON report.

[source,sh]
----
histlog consolidate --root /tmp/histlog --date 2026-05-06
histlog consolidate --root /tmp/histlog --date 2026-05-06 --rebuild
----

`consolidate --rebuild` deletes database rows and checkpoints for that date, then rematerializes them from current closed sessions.
If the local database projection schema is incompatible, `consolidate` may drop and recreate the derived projection from canonical NDJSON. Its JSON report includes `schema_reset: true` when that happens.

Materialization commits inside a SQLite transaction:

* validate closed session NDJSON
* quarantine malformed session files
* insert normalized sessions, command text, paths, command rows, and processed-session checkpoints
* commit all database changes together

If a run stops partway through, SQLite rolls back the incomplete transaction.
The next run can retry safely without duplicating already processed sessions.

`verify` checks the database schema and compares processed-session checkpoints with materialized command rows.

[source,sh]
----
histlog verify --root /tmp/histlog --date 2026-05-06
----
