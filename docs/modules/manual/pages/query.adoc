= Query History
:page-layout: default

`query` searches consolidated SQLite rows and currently live sessions.
It prints a colorized human-readable table by default.

[source,sh]
----
histlog query --root /tmp/histlog --date 2026-05-06 --command mix
histlog query --root /tmp/histlog --date 2026-05-06 --command mix --json
histlog query --today --failed
histlog query "mix test" --plain
----

Public output modes are:

* `--json`
* `--yaml`
* `--plain`
* `--format bash|zsh|fish|nu|powershell`

NDJSON remains an internal storage format and is not a query output mode.
Use `histlog export --format ndjson` for pipelines that need line-oriented JSON.

[source,sh]
----
histlog export --format ndjson --date 2026-05-06
----

Malformed query filters, such as invalid regular expressions or duration expressions, return an error instead of an empty result set.

Use xref:commands.adoc[`histlog commands`] when you want command usage summaries instead of individual execution rows.
